# Prueba Técnica Frontend: Tork® Landing Page + Firebase

Landing page profesional desarrollada como prueba técnica, basada estrictamente en el diseño de Figma proporcionado, con un enfoque responsive y conectada a Firebase Firestore para la captura de registros.

## 🚀 Tecnologías Utilizadas

* **HTML5** (Estructura semántica)
* **CSS3** (Estilos personalizados, Grid, Flexbox y adaptabilidad móvil)
* **JavaScript (ES6+)** (Lógica de interfaz y validaciones)
* **Firebase Firestore** (Base de datos NoSQL en tiempo real)
* **Firebase Hosting** (Despliegue del proyecto)
* **Git & GitHub** (Control de versiones)

---

## 📋 Características de la Solución

1. **Fidelidad Visual (Figma):** Maquetación detallada de secciones (Hero, Video, Features, Solutions, Results, Innovations y Growth) respetando paletas de colores, tipografías e iconografía original.
2. **Diseño Responsivo:** Adaptación completa para dispositivos móviles, tablets y escritorios mediante media queries y estructuras flexibles.
3. **Formulario y Conexión Backend:** 
   * Captura de datos de usuarios (Nombre, Apellido, Celular, Correo empresarial).
   * Envío asíncrono y almacenamiento directo en una colección de **Firebase Firestore**.
   * Retroalimentación visual al usuario tras el registro exitoso.
